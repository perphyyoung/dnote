# git提交信息规范

用于规范 git commit 的提交信息格式；应用时，非必要不添加正文和脚注。

## 约定式提交格式

```text
<类型>[可选范围]: <描述>

[可选正文]

[可选脚注]
```

## 提交类型

| 类型       | 用途                           |
| ---------- | ------------------------------ |
| `feat`     | 新功能                         |
| `fix`      | Bug 修复                       |
| `skill`    | Skill 相关更改                 |
| `docs`     | 仅文档更改                     |
| `style`    | 格式/样式调整（无逻辑变更）    |
| `refactor` | 代码重构（无功能/修复）        |
| `perf`     | 性能优化                       |
| `e2e`      | 添加/更新 e2e 测试             |
| `test`     | 添加/更新其他测试              |
| `build`    | 构建系统/依赖项                |
| `ci`       | CI/配置更改                    |
| `chore`    | 维护/杂项                      |
| `revert`   | 回滚提交                       |

## 破坏性变更

```
# 在类型/范围后加感叹号
feat!: 移除已弃用的接口

# 或使用 BREAKING CHANGE 脚注
feat: 允许配置继承其他配置

BREAKING CHANGE: `extends` 键的行为已更改
```
